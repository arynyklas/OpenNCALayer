# Безопасность

## Как сообщить об уязвимости

Не пишите об уязвимостях в Issues и в чат: они публичные.

Сообщите приватно через GitHub: вкладка **Security** → **Report a vulnerability** ([прямая ссылка](https://github.com/arynyklas/OpenNCALayer/security/advisories/new)). Сообщение увидят только мейнтейнеры.

Опишите, что не так, на какой версии и как это повторить. Не прикладывайте настоящие ключи, пароли и сертификаты: хватит тестовых.

## Что дальше

- Ответ на сообщение — в течение нескольких дней.
- Исправление выходит новой версией; после выхода уязвимость описывается в GitHub Security Advisory.
- Поддерживается только последняя выпущенная версия.
