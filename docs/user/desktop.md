# Программа на компьютере

Здесь описано, что умеет OpenNCALayer после установки: значок в области уведомлений, настройки, мастер сертификата и работа вместе с оригинальным NCALayer. Как поставить программу — в [`install.md`](install.md).

OpenNCALayer живёт в области уведомлений (трее): значок, а от него — окна настроек, плагинов и инструментов. Закрытие окон программу не останавливает.

## Значок в области уведомлений

Запускает значок команда `openncalayer run` (её же вызывает автозапуск). Меню значка:

| Пункт | Что делает |
|---|---|
| «Настройки…» | Язык, автозапуск, прокси, обновления, токены, размер окон |
| «Сертификат для браузера…» | [Мастер сертификата](#мастер-tls) |
| «Инструменты…» | Хеш файла, сведения о сертификате, файле подписи, хранилище ключей и токене. Тот же пункт — команда `openncalayer tools`. Если программа уже запущена, окно откроется в ней |
| «Плагины…» | Установка и удаление [плагинов](plugins.md) |
| «Журнал» | Открывает папку `logs/` |
| «Проверить обновления» | См. [`updates.md`](updates.md) |
| «О программе» | Версия, лицензии |
| «Остановить оригинал…» | Появляется, только когда порт 13579 занял оригинальный NCALayer ([подробнее](#оригинальный-ncalayer)) |
| «Выход» | Останавливает программу полностью |

Окно «Инструменты…» открываете только вы. Запрос сайта и вход в систему его не открывают. Операции плагинов в нём запускаются только после вашего явного подтверждения: вы видите файл, ключ и вид подписи, подтверждение действует один раз ([подробнее](manual-plugins.md)).

**Когда значок просит внимания.** Значок меняется, если:
- сертификат для браузера не настроен;
- сертификат истекает через 60 дней или раньше;
- порт 13579 занят.

Подсказка значка описывает проблему. Уведомления приходят как всплывающее сообщение значка (Windows), уведомление рабочего стола (Linux) или системное уведомление (macOS).

**Без значка.** `openncalayer run --no-tray` работает без значка. Если значок показать нельзя (Linux без поддержки значков, сеанс без области уведомлений), в журнал пишется предупреждение, а программа продолжает подписывать. На Linux при автозапуске программа до минуты ждёт, пока панель будет готова; если панель появилась позже, значок всё равно появится.

## Настройки

Окно «Настройки…» сохраняет выбор в файл `settings.json` в каталоге данных.

| Ключ | Что значит |
|---|---|
| `locale` | Язык окон и значка: `ru`, `kk` или `en`. Если ключа нет, берётся язык системы (из этих трёх), иначе русский |
| `autostart` | «Запускать при входе в систему». Окно показывает настоящее состояние. Если вы выключили запись в Диспетчере задач («Автозагрузка»), она считается выключенной |
| `proxy` | Прокси для проверки сертификатов (OCSP, CRL) и меток времени (TSP). См. ниже |
| `updates` | Автообновление: `{"enabled": true, "channel": "stable"}`, канал `stable` или `beta`. См. [`updates.md`](updates.md) |
| `tokens` | Токены и удостоверение личности: `{"enabled": false}` по умолчанию. См. [`tokens.md`](tokens.md) |
| `ui` | Размер окон и текста: `{"scale": 150}` — процент от системного масштаба: 100, 125, 150, 175 или 200 (по умолчанию 100). Применяется сразу ко всем окнам. Значение не из списка читается как 100 |

Автозапуск записывается так: значение `OpenNCALayer` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (Windows), `~/.config/autostart/openncalayer.desktop` (Linux), `~/Library/LaunchAgents/io.github.arynyklas.openncalayer.plist` (macOS).

**Прокси** (`proxy`):
- `{"mode":"none"}` — без прокси, прямые соединения (по умолчанию, даже если прокси задан в системе);
- `{"mode":"system"}` — прокси из переменных `ALL_PROXY`, `HTTPS_PROXY` или `HTTP_PROXY` (с `NO_PROXY`); в Windows без них берётся прокси из «Свойств браузера»;
- `{"mode":"manual","url":"http://host:port"}` — свой адрес.

SOCKS и прокси по `https://` не поддерживаются. Новый прокси действует сразу, без перезапуска. В файле может лежать пароль прокси, поэтому в macOS и Linux его читает только владелец (права `0600`).

Размер окон можно задать и переменной `SLINT_SCALE_FACTOR`, но это настройка для разработчиков: пока она задана, значение из `settings.json` не применяется.

В окне настроек есть и два блока:
- «Оригинальный NCALayer» — найден ли он и как отключить его автозапуск ([подробнее](#оригинальный-ncalayer));
- «Расширение браузера» — состояние связи с браузером и кнопки «Зарегистрировать» и «Удалить» (то же, что `openncalayer nm install` и `nm uninstall`, см. [`browser-extension.md`](browser-extension.md)).

### Управление с клавиатуры

- Tab и Shift+Tab переходят между элементами, Enter или пробел нажимает кнопку или выбирает строку списка.
- Длинный текст в окне прокручивается стрелками, PageUp/PageDown, Home и End.
- Esc закрывает окно (в диалоге запроса — отменяет его). Вопросам мастера сертификата и удаления плагина Esc отвечает «нет».
- Пока идёт действие (сохранение, остановка оригинала, запись в хранилище доверия), Esc окно не закрывает: нужно увидеть результат.
- На вопрос, который что-то записывает или останавливает, Enter отвечает «нет».

Проверено на заглушке окна без экрана. На реальных окнах Windows (смена масштаба, перенос между мониторами, Windows 7) ещё не проверялось.

## Мастер TLS

Мастер «Сертификат для браузера…» — основной способ настроить сертификат. Он нужен, чтобы сайты в браузере без расширения могли подключиться по `wss://127.0.0.1:13579`. Подробная инструкция и ручные команды — в [`tls.md`](tls.md). Коротко, вкладки мастера:
- **Состояние** — сертификат, срок действия, отпечатки, доверяет ли ему система (только чтение);
- **Источник** — собственный центр сертификации, mkcert или свой сертификат. Новый сертификат начинает работать сразу, без перезапуска;
- **Установка** — по кнопке и после подтверждения: ваш CA, корни НУЦ (`rcarsa20` и `ncarsa22`), удаление ровно этих сертификатов. Сама программа ничего в хранилища не ставит;
- **Проверка** — «Открыть проверку в браузере» открывает `https://127.0.0.1:13579/openncalayer/selftest`.

Срок сертификата проверяется при запуске и раз в сутки. За 60 дней до конца значок просит внимания, а уведомление ведёт в мастер. Сертификат mkcert при вашем согласии перевыпускается сам за 30 дней до конца срока.

## Оригинальный NCALayer

Оригинал и OpenNCALayer не могут одновременно слушать `wss`: обоим нужен порт 13579. Расширение браузера от этого не зависит.

**Остановить оригинал.** Если порт держит оригинал, в меню значка появляется «Остановить оригинал…». Окно показывает программу и номер процесса. После «Остановить» OpenNCALayer ещё раз проверяет, что это тот же процесс (путь и время запуска), завершает его и сам занимает порт. Любой другой процесс программа не трогает.

Оригинал определяется как `NCALayer.exe`, `ncalayer.sh` или Java с `ncalayer` в командной строке.

**Отключить автозапуск оригинала.** Кнопка «Отключить автозапуск оригинала» ничего не удаляет:
- Windows — ярлыки оригинала из папки «Автозагрузка» пользователя переносятся в папку `original-autostart/` каталога данных;
- Linux — в `~/.config/autostart/ncalayer.desktop` ставится `Hidden=true`, а прежний файл копируется в `original-autostart/`;
- macOS — у оригинала автозапуска нет, окно напишет «не найден».

Запись `NCALayer` в `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`, которую делает MSI оригинала, окно только показывает. Отключить её может лишь администратор; окно подскажет как. Записи, которые вы сами выключили (например, в Диспетчере задач), не трогаются.

**Вернуть оригинал.** Кнопка возвращает перенесённые ярлыки и `ncalayer.desktop` на место и выключает наш автозапуск. Оба действия ведут журнал `original-autostart.json`: прерванное действие можно просто повторить, ничего не потеряется.
