# oncl {{VERSION}} ({{FLAVOR}})

`oncl` — программа командной строки OpenNCALayer. С ней можно считать хеши, подписывать и проверять подписи, продлевать их, ставить метки времени, работать с JWS/JWT и вызывать плагины.

Ей не нужна настольная программа OpenNCALayer. Она ничего не устанавливает, не запускает в фоне и пишет только по путям, которые вы укажете. Этот архив — просто программа, а не установщик.

## Быстрый старт

Распакуйте архив куда угодно и запускайте программу из этой папки:

```sh
oncl --version
printf abc | oncl hash --algorithm sha256 --input -
# ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
oncl verify --profile cms --input signature.p7s --root nca-root.der
```

Что нужно знать:
- Списка доверенных сертификатов по умолчанию нет. Корневые сертификаты передайте сами через `--root`.
- Закрытые ключи берутся из файлов PKCS#12/JKS или из смарт-карты, которую вы назовёте.
- Пароли читаются из файла (доступного только вам) или вводятся в терминале. В аргументах команды пароль передать нельзя.
- Чтобы подписать, добавьте `--authorize`. Так вы явно подтверждаете именно эту операцию.

С параметрами `--endpoint https://host:13579 --token-file client.token --ca-file ca.pem` те же команды работают через сервис `oncl-server` (он ставится отдельным пакетом).

Полное описание команд: `docs/cli.md` в этом архиве.
